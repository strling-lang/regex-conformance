# Registries

Machine-operational discovery, universe, release/profile, and namespace registry
definitions live here. Registry snapshots account for unresolved and
unreproducible scope instead of deleting it.

- `discovery/` — source classes, scan methods, and provenance definitions
- `universe/` — candidates, dispositions, entities, lineage, and snapshots
- `profiles/` — releases, component graphs, profile families, and profiles
- `identity/` — namespace and external-reference registry data
