# Applicability

Pure typed applicability rules, capability references, relevant-dimension
expansion policies, and exclusion-reason definitions live here. Evaluation is
total and explainable for every candidate coordinate.

Current conditional-requirement authority is indexed by
`current-authority.v1.json`. The contract consumes frozen profile-capability
facts using open-world semantics: missing is unresolved, while
`not-applicable` requires affirmative negative evidence. Applicability does not
create an expectation, support claim, observation, skip, or conformance verdict.

See [the architecture contract](../docs/architecture/conditional-requirement-applicability.md).
