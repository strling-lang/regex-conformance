# Verifier agent guidance

`verifier/` qualifies immutable observations and manifests for structural,
provenance, result, integrity, reconciliation, replication, and discrepancy
properties. Read [README.md](README.md) and
[../docs/campaigns/evidence-verification.md](../docs/campaigns/evidence-verification.md).

Verification may admit, quarantine, invalidate, supersede, or reconcile by
creating traceable assessment state. It never rewrites published evidence.
Analytical admission does not imply trusted execution or certification
admissibility, and a clean observation does not establish a normative
expectation. Preserve the source evidence for every malformed, partial,
substituted, inconsistent, or superseded case.

Run focused verifier and evidence tests first, then campaign/schema validation.
Use only explicit external evidence paths; never copy raw evidence into Git.
