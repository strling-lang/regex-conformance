# Compatibility projections

Each certified Coverage Shard produces one
`coverage-shard-NNNN.v1.json` Compatibility projection. It records compact
profile × feature × operation outcomes while preserving the exact applicable
semantic-obligation count and coordinate-set digest used for scientific
accounting.

Supported, Unsupported, and Conditional require certified evidence references.
Not Applicable requires a governed exclusion. Unknown is permitted only for an
explicitly certified unreproducible limitation; missing evidence never becomes
Unsupported. Compatibility projections are generated from certified evidence,
not maintained by hand.
