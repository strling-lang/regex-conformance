# Bounded PCRE2 production admission

The exact PCRE2 proposal binds the scientific source, protected envelope,
certificate, adapter, realized profile fingerprint, requests, oracle bindings,
and caps. Retain those proposal bytes unchanged. The operator separately
records the trusted execution admission after independently verifying the
owner's exact authorization and the worker's protected checkout, isolation,
resource admission, runtime fingerprint, and realization identity.

The admission verifier requires the original canonical proposal and the
separately pinned assigned admission. It verifies the ordered logical
population, one serial physical attempt per coordinate, the per-call and total
time limits, and zero remote writes. A certification check or qualification
receipt alone does not admit a worker or an assignment.

The campaign journal uses a directory named for the immutable campaign
manifest and reserves each coordinate before calling the protected
dispatcher. Reservations and closure records are create-once. An interruption
after reservation leaves an uncertain physical dispatch. Preserve the
reservation and reconcile its captured evidence before considering later
coordinates. A committed inconclusive capture cannot be retried in this
assignment. The reserved native request preserves the reviewed semantic
digest and derives its correlation and trace references from the physical
run identity.

Reservation and closure records coordinate dispatch. Evidence admission
independently checks exact native frames, synchronized lineage, terminal
observations, and all relational controls. Retain working evidence outside
Git and distinguish a recovered partial capture from a final evidence pack.

A dispatcher consuming this interface must be present in the protected
source selected by its assignment. It must enforce the worker's actual
resource limits and capture evidence from the target invocation. A new
protected harness that changes pinned execution identity needs a successor
proposal and separate owner authorization.
